> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `robots.ts` and `sitemap.ts` to the Next.js app using MetadataRoute conventions, and set `NEXT_PUBLIC_SITE_URL` in Vercel's production environment.

**Architecture:** Two new files in `app/` use Next.js built-in file conventions — no config changes, no dependencies. Both import `siteUrl()` from the pre-existing `lib/site.ts`. `sitemap.ts` derives all 16 URLs from the content layer (`content/experience.ts`, `content/projects.ts`).

**Tech Stack:** Next.js 16, TypeScript, `MetadataRoute` from `next`, Vercel CLI.

import { siteUrl } from "@/lib/site";

## Task 2: Create `app/sitemap.ts`

**Files:**
- Create: `app/sitemap.ts`

- [ ] **Step 2.1: Create the file**

```ts
// app/sitemap.ts
import type { MetadataRoute } from "next";
import { siteUrl } from "@/lib/site";
import { caseStudies } from "@/content/experience";
import { projectCaseStudies, projectTeardowns } from "@/content/projects";

export default function sitemap(): MetadataRoute.Sitemap {
  const base = siteUrl();

  const staticRoutes = ["/", "/about", "/projects"].map((path) => ({
    url: `${base}${path}`,
  }));

  const experienceRoutes = caseStudies.map((c) => ({
    url: `${base}/experience/${c.slug}`,
  }));

  const projectRoutes = [...projectCaseStudies, ...projectTeardowns].map((p) => ({
    url: `${base}/projects/${p.slug}`,
  }));

  return [...staticRoutes, ...experienceRoutes, ...projectRoutes];
}
```

- [ ] **Step 2.2: Verify TypeScript compiles**

```bash
npx tsc --noEmit
```

Expected: no output (zero errors).

- [ ] **Step 2.3: Verify the route renders 16 entries in dev**

With dev server running from Task 1:

```bash
curl http://localhost:3000/sitemap.xml
```

Expected: XML with 16 `<url>` entries. Count them:

```bash
curl -s http://localhost:3000/sitemap.xml | grep -c '<loc>'
```

Expected output: `16`

The 16 entries are:
- Static (3): `/`, `/about`, `/projects`
- Experience (2): `/experience/hebe`, `/experience/nwn`
- Projects (11): `/projects/netflix`, `/projects/amazon-prime`, `/projects/cred`, `/projects/blinkit`, `/projects/sportskeeda`, `/projects/groww`, `/projects/spotify`, `/projects/cult-fit`, `/projects/zerodha`, `/projects/instagram`, `/projects/zoom`

All URLs should begin with `http://localhost:3000` in dev.

- [ ] **Step 2.4: Verify production build passes**

```bash
npm run build
```

Expected: build completes with zero errors. `sitemap` and `robots` appear as `○ (Static)` routes in the output table.

- [ ] **Step 2.5: Commit**

```bash
git add app/sitemap.ts
git commit -m "feat: add sitemap.ts (16 routes from content layer)"
```
